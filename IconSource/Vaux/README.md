# Vaux app icon layers

Layer art for Icon Composer. Every SVG is a full 1024 × 1024 canvas with the
shape already in place, so layers line up when dropped in. Colors in the files
are only defaults; set the real ones per appearance in Icon Composer.

The five center bars are the menu bar glyph (`Sources/StatusIcon.swift`, live
state) scaled up: same widths, spacing and heights, so the app icon and the
menu bar icon are one shape.

| File | What it is |
|---|---|
| `bars.svg` | The five voice bars |
| `side-bars.svg` | One quieter bar on each side, on the same spacing |
| `preview-light.png`, `preview-dark.png` | Reference renders, not layers |

## Colors

| Layer | Light (Default) | Dark |
|---|---|---|
| Background fill | gradient `#FBFBFD` → `#DFE2EA` (top → bottom) | gradient `#2A2D38` → `#121318` |
| `bars` | `#1E2230` | `#F1F2F6` |
| `side-bars` | `#C3C7D1` | `#4C5060` |

Mono (tinted and clear) is generated by Icon Composer from these layers.

## Assembling

1. Open Icon Composer (`/Applications/Xcode-beta.app/Contents/Applications/Icon Composer.app`) and create a new icon.
2. Set the background fill to the light gradient above.
3. Drag in `side-bars.svg`, then `bars.svg` so the bars sit on top.
4. Set each layer's fill for Default and Dark from the table.
5. Save as `Vaux.icon`.
