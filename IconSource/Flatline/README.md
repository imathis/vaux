# Flatline icon layers

Layer art for Icon Composer. Every SVG is a full 1024 × 1024 canvas with the
shape already in place, so layers line up when dropped in. Colors in the files
are only defaults; set the real ones per appearance in Icon Composer.

| File | Used by | What it is |
|---|---|---|
| `bars.svg` | Paper | The four bars as one layer |
| `bar-1.svg` … `bar-4.svg` | Spectrum | Each bar on its own layer, so each can have its own color |
| `line.svg` | both | The flat line |

## Paper (default icon)

| Layer | Light (Default) | Dark |
|---|---|---|
| Background fill | gradient `#FBFBFD` → `#DFE2EA` (top → bottom) | gradient `#2A2D38` → `#121318` |
| `bars` | `#1E2230` | `#F1F2F6` |
| `line` | `#F0443A` | `#FF5B50` |

## Spectrum (alternate)

| Layer | Light (Default) | Dark |
|---|---|---|
| Background fill | gradient `#FBFBFD` → `#DFE2EA` | gradient `#1C1E28` → `#0A0B0F` |
| `bar-1` | `#12B5AE` | `#3FDCD6` |
| `bar-2` | `#2F7BFF` | `#4FA2FF` |
| `bar-3` | `#6A57F2` | `#7C6CFF` |
| `bar-4` | `#9B4BEF` | `#B46BFF` |
| `line` | `#1E2230` | `#FFFFFF` at 90% |

Mono (tinted and clear) is generated by Icon Composer from these layers.
